# README banner

`pach-banner.png` is a 1600 × 500 PNG. The background was generated with the built-in imagegen tool; the supplied PACH wordmark and tagline were composited afterward with Sharp so the logo lettering stays intact. The source wordmark is in `apps/web/public/brand/pach-wordmark.png`.

Generation prompt:

> Create a minimalist editorial GitHub README banner background for PACH, a playful product-testing tool. Wide landscape 3:1 aspect ratio, ideally 1800 by 600. Flat warm white background (#ffffff). Restrained cobalt blue (#2563eb), navy, and very pale cool gray. LEFT 60% COMPLETELY EMPTY WHITE, reserved for an existing logo and a short tagline to be composited later. On the right 35%, a beautifully balanced, sparse graphic: three thin precise navy outlines of rounded rectangular interface tiles stepping slightly diagonally upward; one cobalt blue square displaced from an otherwise orderly pale gray grid, suggesting discovering and fixing a small glitch. A small cobalt circular annotation around the displaced tile. Fine lines, generous negative space, crisp Swiss graphic design, subtle paper-like depth at most, sophisticated and quiet. Keep every graphical element comfortably inside the frame with wide margins. No text, letters, logos, typography, people, crypto symbols, gradients, glossy 3D, heavy shadows, noise, or watermarks.
