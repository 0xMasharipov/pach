# Release gates

Code implementation is separate from a successful deployment. Current verification details are in PROGRESS.md and WORK_LOG.md.

- [ ] Complete registry-backed dependency install and reviewed application lockfile.
- [ ] Full Fastify build, typecheck and transport tests with installed dependency.
- [ ] PostgreSQL migration, concurrent transactions and restart persistence on a running database.
- [ ] Docker build and Compose startup on a permitted host.
- [ ] Monad-capable Foundry tests and fresh official network verification.
- [ ] Configured operator wallets, verifier and deployment access.
- [ ] Actual Testnet vault deployment and source verification.
- [ ] Receipt-confirmed 20 test USDC funding.
- [ ] Receipt-confirmed 4 finder and 14 developer claims, with 2 platform fee.
- [ ] Stable public HTTPS host, exact origin and production cookies.
- [ ] HTTP browser checks and mobile device/wallet rehearsal.
- [ ] Real dated demo recording, screenshots and explorer links.
- [ ] Usable Git repository, reviewed commit and repository URL.
- [ ] Confirm event submission details from the organizer.

No item above is implied complete by a unit test or rendered preview.
